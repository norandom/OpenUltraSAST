# Engine traces on kube-ax

`benchmarks/learn/engine_trace.py --executor ax` sends an engine trace run to AX Tasks on kube-ax,
with one local Docker lane as the fallback. The runbook is the maintainer's: it names the paths of the
coordinator host.
